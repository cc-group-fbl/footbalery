# Электронные протоколы Footbalery

## Текущий этап

Добавлена безопасная SQL-миграция `supabase/migrations/20261120_match_protocols.sql`.
Она создаёт отдельные таблицы назначений и отправленных протоколов и три RPC-функции:

- `admin_assign_match_referee` — назначение судьи администратором на матч;
- `submit_match_protocol` — отправка протокола только назначенным судьёй;
- `admin_review_match_protocol` — одобрение или возврат протокола на исправление администратором.

Существующие `matches`, `schedule_events` и записи расписания миграция не изменяет.

## Установка

1. Открой Supabase проекта Footbalery → SQL Editor.
2. Открой файл `supabase/migrations/20261120_match_protocols.sql` в GitHub.
3. Скопируй весь SQL в SQL Editor и выполни.
4. Убедись, что запрос завершился без ошибок.

## Принцип безопасности

- Назначение может создавать или менять только пользователь с ролью `admin` в `profiles`.
- Отправить протокол может только пользователь, назначенный на конкретный `match_id`.
- Судья видит только собственные назначения и протоколы.
- Администратор видит все протоколы.
- Изменение статуса проверки доступно только через защищённую RPC-функцию.
- Счёт проверяется на неотрицательные целые числа, оценки судей — в диапазоне 0–10.

## Следующие шаги интерфейса

После установки SQL подключить интерфейс:
1. В админ-панели — назначение судьи на выбранный матч.
2. В кабинете назначенного судьи — форма заполнения и отправки.
3. В админ-панели — очередь «На проверке», одобрение и возврат на исправление.
4. Отдельно настроить загрузку файла протокола в приватное хранилище Supabase.

## Важное ограничение интеграции с Memento

На этом этапе протоколы сохраняются в Supabase и доступны для проверки в Footbalery. Передача одобренной записи в Memento ещё не реализована: для неё нужен работающий мост из Mini App Memento или иной подтверждённый канал. Не считать статус «Одобрен» автоматической записью в Memento.
